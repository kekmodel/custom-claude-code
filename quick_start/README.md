# Quick Start - 빠른 시작 스크립트

이 폴더에는 각 버전을 빠르게 체험할 수 있는 간단한 스크립트들이 있습니다.

## 파일 목록

### simple_v1.py
**목적:** v1 (OpenAI API 직접 구현) 빠른 시작
**기능:** v1의 실제 대화 루프 실행

**실행:**
```bash
uv run python quick_start/simple_v1.py
```

---

## 권장 사항

**대부분의 경우, launcher.py를 사용하는 것을 권장합니다:**

```bash
uv run python launcher.py
```

launcher.py는 4가지 버전을 모두 선택해서 실행할 수 있는 대화형 UI를 제공합니다.

---

## quick_start vs launcher.py

| 특징 | quick_start/ | launcher.py |
|------|--------------|-------------|
| **선택 UI** | 없음 | 있음 (대화형) |
| **버전 선택** | 파일별로 고정 | 런타임 선택 가능 |
| **사용 난이도** | 매우 쉬움 | 쉬움 |
| **용도** | 특정 버전만 빠르게 테스트 | 여러 버전 비교 |

---

## 용도

- **빠른 테스트**: 특정 버전만 즉시 실행
- **학습**: 각 버전의 코드 구조 이해
- **개발**: 버전별 기능 개발 및 테스트
